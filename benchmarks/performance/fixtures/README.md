# Fixtures (fictional)

Generated by `python3 -m imx_perf fixtures`. Every company, tenant, job id, URL
(`.example` domains), description and the candidate are invented for offline
benchmarking. Nothing here describes a real employer, posting or person, and nothing
here is calibration data for Jev.

| File | Contents |
| --- | --- |
| `assumptions.default.json` | the default `Assumptions` (edit a copy and pass `--assumptions`) |
| `assumption_provenance.json` | observed / modeled / external label and note per assumption |
| `population.seed42.json` | 2 000 fictional listings in the D0 `JobListing` JSON shape plus a private `truth` block |
| `question_catalog.json` | per-ATS question sets used to model human input |
| `candidate_evidence.fictional.json` | the fictional candidate's verified-qualification projection |
